GETTING STARTED

Quick start

  1. 1. Create a requestOpen Studio, enter an HTTP(S) URL and select a method.
  2. 2. Customize and sendSet query parameters, headers or a body, then send your request.
  3. 3. Inspect the responseReview status, response body and headers in Inspector.
FEATURES

What you can do

  • Collections: save requests and environments.
  • Tests: check HTTP status and response latency.
  • Explore: inspect authorized endpoints with safeguards.
  • Extensions: access built-in tools and planned capabilities.
SECURITY

Privacy and safety

  • Requests are sent only when you run them.
  • Workspace data stays local according to the storage mode you choose.
  • Browsers enforce CORS and restrict certain headers.
  • Only explore endpoints you are authorized to test.
